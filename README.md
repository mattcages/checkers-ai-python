# Python Checkers Game

A simple checkers (draughts) game developed in Python.
This project was created as part of my learning journey in programming and game logic.

## Features

* Classic checkers gameplay
* Turn-based system
* Piece movement validation
* Capture mechanics
* Simple and clean code structure

## Technologies Used

* Python 3

## Installation

1. Clone the repository:

```
git clone https://github.com/mattcages/checkers-ai-python.git
```

2. Navigate to the project folder:

```
cd jeu-de-dames-python
```

3. Run the game:

```
python main.py
```

---

## How to Play

* Players take turns moving their pieces diagonally
* Capture opponent pieces by jumping over them
* The goal is to eliminate all opponent pieces or block their moves
